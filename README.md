# یادداشت کتاب‌ها

سایت ساده و بدون نیاز به بیلد برای نگهداری خلاصه‌ی کتاب‌ها، با Markdown و Git.

## ساختار پروژه

```
.
├── index.html      فهرست همه‌ی کتاب‌ها
├── book.html       صفحه‌ی نمایش خلاصه‌ی یک کتاب
├── style.css       استایل مشترک
├── app.js          توابع خواندن و پارس فایل‌های Markdown
├── books.json      لیست اسلاگ فایل‌هایی که باید نمایش داده شوند
└── books/
    ├── sapiens.md
    └── the-little-prince.md
```

## افزودن کتاب جدید

۱. یک فایل جدید در `books/` بساز، مثلا `books/1984.md`

۲. این ساختار را رعایت کن:

```markdown
---
title: عنوان کتاب
author: نام نویسنده
category: توسعه فردی
year_read: 1404
date_read: 1404/03/01
read_minutes: 10
rating: 4
tags: [تگ۱, تگ۲]
quote: یک نقل‌قول کوتاه و مورد علاقه از کتاب
---

## خلاصه
متن خلاصه...

## نکات کلیدی
- نکته اول
- نکته دوم

## برداشت من
- برداشت اول
- برداشت دوم
```

فقط `title` لازم است؛ بقیه فیلدها اختیاری‌اند و اگر خالی بمانند، به سادگی نمایش داده نمی‌شوند.

نکات درباره‌ی فرمت:
- `category` برای دسته‌بندی و فیلتر کتاب‌ها در صفحه‌ی اصلی استفاده می‌شود.
- عنوان بخش‌های `## خلاصه`، `## نکات کلیدی` و `## برداشت من` (یا `برداشت شخصی`) به‌طور خودکار با طراحی ویژه (شماره‌گذاری دایره‌ای، تیک) نمایش داده می‌شوند؛ هر عنوان دیگری هم به‌شکل یک بخش ساده رندر می‌شود.
- اگر فیلد `cover` را ندهی، جلد هر کتاب به‌صورت خودکار و بر اساس نام فایل رنگ‌آمیزی می‌شود.

## افزودن عکس جلد برای یک کتاب

۱. عکس جلد را (ترجیحاً با نسبت ابعاد عمودی، حدود ۳:۴) در پوشه‌ی `covers/` بگذار، مثلاً:
```
covers/atomic-habits.jpg
```

۲. فیلد `cover` را به فرانت‌متر همان کتاب اضافه کن:
```markdown
---
title: عادت‌های اتمی
cover: covers/atomic-habits.jpg
...
---
```

۳. کامیت و پوش کن. همین.

نکات:
- برای بهترین کیفیت، عکس را حدود ۶۰۰ در ۸۰۰ پیکسل و فرمت `.jpg` یا `.webp` (سبک‌تر از png) انتخاب کن تا سایت سریع بارگذاری شود.
- اگر عکس جلد واقعی کتاب را از اینترنت می‌گیری، توجه داشته باش که جلدهای کتاب معمولاً کپی‌رایت دارند؛ برای یک آرشیو کاملاً شخصی معمولاً مشکلی پیش نمی‌آید، ولی اگر سایت را عمومی و پرمخاطب می‌کنی بهتر است از عکس‌های خودت یا منابع آزاد (مثل Open Library Covers API) استفاده کنی.
- می‌توانی بعضی کتاب‌ها عکس داشته باشند و بعضی نه؛ هرکدام که `cover` نداشته باشد، همان جلد رنگی خودکار را می‌گیرد.

۳. اسلاگ فایل (بدون پسوند `.md`) را به آرایه‌ی `books.json` اضافه کن:

```json
[
  "sapiens",
  "the-little-prince",
  "1984"
]
```

۴. تغییرات را کامیت و پوش کن:

```bash
git add .
git commit -m "add: خلاصه‌ی 1984"
git push
```

## دیپلوی روی GitHub Pages

۱. ریپو را در گیت‌هاب بساز و کد را پوش کن.
۲. در تنظیمات ریپو، بخش **Pages** را باز کن.
۳. بخش Source را روی برنچ `main` و پوشه‌ی `/ (root)` بگذار.
۴. سایت روی آدرسی شبیه `https://username.github.io/repo-name/` بالا می‌آید.

> نکته: چون فایل‌های Markdown با `fetch` خوانده می‌شوند، باز کردن `index.html` مستقیم از روی دیسک (`file://`) کار نمی‌کند — باید از طریق یک سرور محلی (مثلا `python3 -m http.server`) یا هاستی مثل GitHub Pages باز شود.

## اجرا روی سیستم شخصی (قبل از پوش کردن)

```bash
python3 -m http.server 8000
```

سپس آدرس `http://localhost:8000` را باز کن.

## سفارشی‌سازی

- رنگ‌ها و فونت در `style.css` (متغیرهای `:root`) قابل تغییرند.
- منطق نمایش و جستجو در `index.html` و `book.html` است؛ چون از هیچ فریم‌ورکی استفاده نشده، تغییر دادنش ساده است.
